# Seghani Tak — Unity source

Open this project in Unity 2023.1.22f1 and load `Assets/Scenes/room.unity`. The scene is populated at runtime. Five selectable levels share the earthquake, cover, result, and restart loop.

Controls: WASD/arrows, mouse look, C/Ctrl crouch, E interact, H help, Esc pause.

This source snapshot includes the current Codex-assisted local changes used for the 15 November 2026 macOS and Windows x64 builds.
